# Runtime dependencies
# =============================================================================
# This project has NO third-party runtime dependencies. All functionality is
# implemented with the Python standard library, therefore:
#
#     pip install -r requirements.txt
#
# installs nothing. This is expected behaviour, not an error.
#
# Standard library modules used
#   __future__, argparse, ctypes, html, os, re, sys, time, tkinter, traceback,
#   winsound
#
# Platform and interpreter constraints
#   * OS       : Windows 10 / 11 (x64). The tool calls user32.dll (SendInput,
#                clipboard APIs) and imports ctypes.wintypes / winsound, all of
#                which are Windows-only.
#   * Python   : >= 3.8 (developed and verified on CPython 3.12).
#   * tkinter  : bundled with the python.org installer; required only by the
#                self-test script and the optional --gui mode.
#
# Build-time only (packaging to a standalone executable, NOT needed to run):
# pyinstaller>=6.0
#
# NOTE: keep this file ASCII-only. pip decodes requirement files with the system
# locale codec (GBK on Chinese Windows); non-ASCII comments raise
# UnicodeDecodeError before any requirement is parsed.
